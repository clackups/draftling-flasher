Draftling for Linux

The Draftling editor as a program for a Linux computer: a Wayland or X11 window, the computer's own keyboard and mouse, every language.

Install firmware on a Draftling device · How to set up Git synchronization

Which package?

  • Debian package -- for Debian 12, Ubuntu 22.04 and later, and distributions based on them (Linux Mint, Raspberry Pi OS, ...). It can also set the screen brightness, show the battery level and connect to WiFi networks through NetworkManager.
  • Flatpak -- for any distribution with Flatpak (Fedora, Arch, openSUSE, Ubuntu, ...), on 64-bit PCs and 64-bit ARM computers. It runs in a sandbox: it uses the computer's network connection as it is (no WiFi menu), and has no brightness setting and no battery indicator.

1 Debian package (Draftling 1.0.33)

Pick the package for your computer's processor (dpkg --print-architecture prints amd64, arm64 or armhf).

  • Download for amd64 draftling_1.0.33_amd64.deb

    64-bit Intel and AMD PCs and laptops.

  • Download for arm64 draftling_1.0.33_arm64.deb

    64-bit ARM computers: Raspberry Pi 3 / 4 / 5 with a 64-bit OS, other ARM single-board computers and laptops.

  • Download for armhf draftling_1.0.33_armhf.deb

    32-bit ARM computers (ARMv7 with hardware floating point): Raspberry Pi 2 / 3 / 4 with a 32-bit OS, older ARM single-board computers.

Install it from the folder you saved it to, then start Draftling from the application menu or with draftling in a terminal:

sudo apt install ./draftling_1.0.33_amd64.deb
draftling

Your documents are kept in ~/.local/share/draftling, the settings in ~/.config/draftling. A newer package installs over the old one the same way; sudo apt remove draftling uninstalls it and leaves your documents in place.

2 Flatpak (Draftling 1.0.33)

Needs Flatpak with the Flathub repository set up (instructions for each distribution). Pick the bundle for your processor (uname -m prints x86_64 or aarch64).

  • Download for x86_64 draftling_1.0.33_x86_64.flatpak

    64-bit Intel and AMD PCs and laptops.

  • Download for aarch64 draftling_1.0.33_aarch64.flatpak

    64-bit ARM computers: Raspberry Pi 4 / 5 with a 64-bit OS, other ARM single-board computers and laptops. (32-bit ARM: use the Debian package.)

Install it from the folder you saved it to (Flatpak downloads the Freedesktop runtime it needs from Flathub the first time), then start Draftling from the application menu or from a terminal:

flatpak install --user ./draftling_1.0.33_x86_64.flatpak
flatpak run art.draftling.Draftling

Your documents are kept in ~/.var/app/art.draftling.Draftling/data/draftling, the settings in ~/.var/app/art.draftling.Draftling/config/draftling. To install a newer bundle, run the same flatpak install command with its file name. flatpak uninstall --user art.draftling.Draftling removes the program; add --delete-data to remove your documents and settings as well.

3 Getting started

  • Draftling starts with the list of projects: a project is a folder of documents that is synchronized with its own Git repository.
  • F1 opens the menu (settings, sync, keyboard layouts), F10 the help page with every keyboard shortcut.
  • Set up Git sync to keep your writing backed up in a private repository, and to move it between the computer and a Draftling device.
